## 增强版看板新功能

### 状态筛选
在筛选栏新增「状态」标签组，点击可分别筛选:
- **全部** — 显示所有活动
- **未举办** — 报名中 + 即将举办 (尚未举行的活动)
- **报名中** — 已确认、开放报名
- **即将举办** — 已定档、尚未开始
- **已举办** — 已完成

### 手动导出 Excel
点击筛选栏右侧「导出 Excel」按钮，可将当前筛选结果导出为 Excel 文件。
导出字段: 活动名称、日期、主办单位、类型、议题、状态、举办地址、报名方式、详情链接。

### 新增字段
活动卡片中新增「举办地址」「报名方式」信息展示。

## 自动监控系统

### 工作流程
1. 从看板 HTML 或 JSON 加载现有活动数据
2. 联网抓取 9 个监控来源的列表页
3. 按关键词筛选命中链接，抓取详情页提取活动信息
4. 合并新活动 (按标题去重)
5. 自动更新过期活动状态 (未举办 → 已举办)
6. 更新看板 HTML 内嵌数据
7. 导出未举办活动为 Excel

### 监控来源 (9个)
北京市商务局、中关村管委会、北京CBD管委会、北京市经信局、德勤中国、毕马威中国、中欧国际工商学院、全球化智库CCG、服贸会组委会

### 定时执行
每周一、三、六 上午 09:00 自动执行。

### 手动运行

```bash
cd monitor

# 完整流程 (联网抓取 + 更新看板 + 导出Excel)
python3 main.py

# 仅导出 Excel (不联网，基于现有数据)
python3 main.py --export-only

# 测试模式 (验证解析和导出，不联网)
python3 main.py --test
```

### 安装定时任务

```bash
cd 北京企业出海活动监控看板
./install_schedule.sh           # 安装
./install_schedule.sh remove    # 卸载
```

安装后，macOS launchd 会在每周一、三、六 09:00 自动执行监控脚本。
日志输出到 `logs/` 目录，Excel 文件输出到 `exports/` 目录。

### 依赖安装

```bash
pip3 install openpyxl lxml
```

## 输出文件命名

Excel 文件: `未举办活动_YYYYMMDD.xlsx` (如 `未举办活动_20260728.xlsx`)
若同一天多次运行，自动加版本号: `未举办活动_20260728v1.xlsx`

## 配置调整

如需修改监控来源、关键词等配置，编辑 `monitor/config.py`:
- `SOURCES` — 监控来源列表 (URL、抓取页面)
- `KEYWORDS` — 关键词列表 (用于匹配活动标题/链接)
- `VENUE_MAP` — 已知活动举办地址
- `REQUEST_DELAY` — 请求间隔 (秒)

## 注意事项

- 联网抓取依赖目标网站可访问性，政府网站偶尔会改版或维护，如长期无法访问请检查 `config.py` 中的 URL 是否需要更新
- 首次运行完整流程 (`python3 main.py`) 后，活动数据会保存到 `data/events.json`，后续运行优先从 JSON 加载
- 定时任务需要电脑处于开机/唤醒状态才能执行，如果错过会跳过该次执行
- 日志文件保留在 `logs/` 目录，可用于排查问题
